# 🎡 วงล้อสุ่มชื่อนักเรียนสำหรับห้องเรียน (Classroom Wheel of Names)

> เว็บแอปพลิเคชันสุ่มชื่อนักเรียน สุ่มผู้โชคดี และสุ่มจัดกลุ่มในห้องเรียน ออกแบบมาเพื่อคุณครูโดยเฉพาะ โทนสว่างสดใส ตัวอักษร Kanit ขนาดใหญ่อ่านง่ายบนจอทีวี/โปรเจกเตอร์ **ไม่มีโฆษณา 100%**

---

## ✨ จุดเด่น & ฟังก์ชันการใช้งาน

- 🎯 **วงล้อฟิสิกส์คมชัดระดับ Retina (Canvas HiDPI)**: หมุนลื่นไหล ตัวหนังสือคมชัดแม้เปิดบนจอโปรเจกเตอร์ความละเอียดสูง
- 🔊 **ระบบเสียงสังเคราะห์ในตัว (Web Audio API)**:
  - เสียงติ๊กของเข็มชี้ตามความเร็วการหมุน
  - เสียงดนตรีฉลองชัย (Fanfare) เมื่อได้ผู้โชคดี
  - ทำงานออฟไลน์ได้ ไม่ต้องโหลดไฟล์เสียงภายนอก
- 👑 **หน้าต่างประกาศผล & พลุกระดาษ (Confetti)**:
  - ตัวหนังสือขนาดใหญ่พิเศษ สะดุดตาทั้งห้องเรียน
  - ปุ่ม **"ลบชื่อนี้ออก"** เพื่อสุ่มคนถัดไปโดยไม่ซ้ำ
- 🏫 **ระบบจัดการห้องเรียน (Classroom Manager)**:
  - บันทึกรายชื่อแยกตามห้องได้ไม่จำกัด (เช่น ม.1/1, ม.1/2, กลุ่มกิจกรรม)
  - สลับห้องเรียนได้ใน 1 คลิก
  - ข้อมูลบันทึกลงเครื่องผู้ใช้ (LocalStorage) อัตโนมัติ ปิดเว็บเปิดใหม่ข้อมูลไม่หาย
- 👥 **สุ่มจัดกลุ่มนักเรียน (Team Generator)**:
  - สุ่มแบ่งกลุ่มนักเรียน 2 - 8 กลุ่มใน 1 คลิก พร้อมคัดลอกรายชื่อไปใช้งาน
- 📺 **โหมดฉายเต็มจอ (Fullscreen Presentation)**:
  - ซ่อนแถบเมนูที่ไม่จำเป็น ขยายวงล้อเต็มหน้าจอเพื่อการสอนที่ราบรื่น
- ⌨️ **ปุ่มลัด (Shortcut)**:
  - กดปุ่ม `Spacebar` เพื่อหมุนวงล้อได้ทันที
  - กดปุ่ม `ESC` เพื่อปิดหน้าต่างหรือออกจากโหมดเต็มจอ

## 🚀 วิธีนำขึ้น Vercel (Deployment Guide)

### วิธีที่ 1: Deploy ผ่าน Vercel Dashboard (แนะนำ - ง่ายที่สุด)
1. ไปที่เว็บไซต์ [https://vercel.com](https://vercel.com) และเข้าสู่ระบบด้วย GitHub
2. กดปุ่ม **"Add New..."** -> **"Project"**
3. เลือก Repository `WheelofnameV2` จากรายการ
4. กดปุ่ม **"Deploy"** (โปรเจกต์นี้ตั้งค่า `vercel.json` ไว้พร้อมแล้ว สามารถ Deploy ได้ทันทีโดยไม่ต้องตั้งค่า Build Command เพิ่มเติม)
5. รอประมาณ 15-30 วินาที จะได้รับ URL เว็บไซต์พร้อมใช้งานทันที เช่น `https://wheelofname-v2.vercel.app`

### วิธีที่ 2: Deploy ผ่าน Vercel CLI
```bash
npm install -g vercel
vercel
```

## 💻 วิธีทดสอบบนเครื่อง Local

1. ติดตั้ง Node.js (หากยังไม่มี)
2. เปิด Terminal ในโฟลเดอร์โปรเจกต์
3. รันคำสั่ง:
```bash
npm run dev
```
4. เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

## 📁 โครงสร้างโปรเจกต์

```
Wheelofname/
├── index.html           # โครงสร้างหน้าเว็บหลักและโมดอล
├── vercel.json          # ไฟล์ตั้งค่าความปลอดภัยและการนำขึ้น Vercel
├── package.json         # กำหนด Metadata และคำสั่งรัน Server
├── .gitignore           # ละเว้นไฟล์ขยะ
├── README.md            # คู่มือการใช้งาน
├── css/
│   ├── main.css         # ดีไซน์หลัก โทนสีฟ้าสดใส และ Design System
│   ├── wheel.css        # สไตล์วงล้อ เข็มชี้ และปุ่มสปิน
│   ├── modal.css        # สไตล์ป๊อปอัปผู้ชนะ สุ่มจัดกลุ่ม และการตั้งค่า
│   └── responsive.css   # รองรับหน้าจอทุกขนาดและสมาร์ทบอร์ด
└── js/
    ├── app.js           # ตัวควบคุมการทำงานหลักและ Events ทั้งหมด
    ├── wheel.js         # Canvas Wheel Engine พร้อมระบบฟิสิกส์
    ├── audio.js         # Web Audio API ระบบเสียงสังเคราะห์
    ├── confetti.js      # Particle System พลุกระดาษฉลองชัย
    ├── storage.js       # จัดการข้อมูลห้องเรียนและ LocalStorage
    ├── history.js       # บันทึกประวัติผู้ชนะ
    └── groups.js        # สุ่มจัดกลุ่มนักเรียน
```
